# Chadex 0.1.0 RC1

This is the first public release candidate of Chadex.

## Scope

- Native macOS Chadex app and helper/runtime bundle.
- Apple Silicon (`arm64`) only for this release candidate.
- Apache-2.0 repository licensing with retained WebCodex upstream attribution.
- Release source is built from the clean public-history branch, not from the private development-history branch.

## Free macOS distribution model

RC1 follows the same practical macOS distribution model currently documented by WebCodex Desktop: the GitHub Release artifact is **ad-hoc signed and not notarized**. Chadex still enables Hardened Runtime, verifies every bundled executable, publishes a SHA-256 checksum, and builds the DMG from the exact tagged public commit.

Because the app is not notarized, macOS may block the first launch after download. Open **System Settings → Privacy & Security**, choose **Open Anyway** for Chadex, then confirm **Open**. Do not disable Gatekeeper globally.

Developer ID signing and Apple notarization remain an optional future upgrade, not a requirement for the free GitHub release.

## Known release boundary

RC1 supports Apple Silicon only. Intel / Universal support is not claimed.
