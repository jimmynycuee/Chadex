# Chadex 0.7.1

Chadex 0.7.1 improves the reliability of Plan Mode and Goal Mode. Public distribution remains the macOS Apple Silicon DMG; Windows remains an unsigned CI validation candidate.

## Changes

- Fixed Plan and Goal follow-up routing, including manifest-first Skill discovery and gateway parameter forwarding.
- Preserved saved plans and approvals across app startup and ChatGPT disconnects, with project-scoped cleanup.
- Added bounded, single-flight backend recovery and transport diagnostics. Requests with an unknown dispatch outcome are not replayed.
- Tightened cancellation and recovery lifecycle handling while preserving isolated Goal worktrees and acceptance checks.

## Validation

- Candidate suites passed: runtime engine 2,804 tests (3 ignored), runtime store 189, tool contracts 142, tool-runtime contracts 96, helper 362 (4 ignored; 3 integration tests), and Swift 267 executed (1 skipped).
- In recorded ChatGPT and tunnel acceptance, a human approved the exact Plan revision; approval survived reconnect and app restart. A server-only recovery restored readiness in about 8.3 seconds while retaining the Runner process identity. ChatGPT made the planned isolated fixture change and its recorded validation exited successfully.
- A human started a ChatGPT-mode Goal; the isolated Goal worktree passed its acceptance checks on the first iteration.
- The formal clean-source release gate and tag workflow provide the version-specific build and package checks for this release.

## Known limitations

- The original 502 incident's root cause remains unconfirmed.
- Live ChatGPT acceptance covered the recorded isolated scenarios, not every provider, network failure or long-running Goal.
- The free macOS artifact is ad-hoc signed and not notarized. Windows remains unsigned and is not publicly distributed.
