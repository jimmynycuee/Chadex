# Chadex 0.6.1

Chadex 0.6.1 is a patch release for macOS button rendering. Public distribution remains the macOS Apple Silicon DMG; the Windows application remains an unsigned CI validation candidate.

## Changes

- **Button label scaling (macOS)**: at interface sizes of 115% and above, button labels were scaled by the full font rate and overfilled the bezel, so they looked off-centre. This was a regression from the design v2 work in 0.6.0 (#2). Labels now scale at the control rate.
- **Capsule buttons (#20)**: all buttons use the capsule shape of the status pills.

## Known limitations

The 0.6.0 limitations still apply; see `docs/releases/0.6.0.md`.

## Validation

Required items, to be confirmed on the release commit at release time:

- The maintainer accepted the development build on a physical Mac.
- `scripts/release_check.sh` exit 0 on the release commit.
- Full CI success on the release commit.

## Distribution boundary

`.github/workflows/release.yml` remains the free macOS distribution path and does not publish the Windows candidate. Publishing Windows assets, enabling a Windows updater or changing the signing policy requires a separate explicit release decision.
