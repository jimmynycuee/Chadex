# Chadex 0.7.2

## Highlights

- **More reliable Goal runs:** execution-environment preflight, isolated acceptance lanes, immutable acceptance revisions, checkpoint-aware retries, and resumable recovery preserve progress after recoverable failures. Security sandboxing remains fail-closed; real owner authorization and formal external gates are still required for Goal success.
- **No duplicate Plan or Goal runs:** repeated start actions reconcile to the existing request instead of creating a second effective run.
- **Windows stays connected when hidden:** the title-bar X and in-app close button hide Chadex to the system tray while the helper and Tunnel keep running. Only **Quit** in the tray menu stops the helper.
- **Windows installer and in-app updates:** v0.7.2 includes a Windows x64 GitHub Release installer and a Tauri-signed update channel. v0.7.1 and earlier must be upgraded by installing v0.7.2 manually; later versions can be installed through the in-app updater. The update signature is checked against the announced app version.
- **macOS distribution:** Apple Silicon DMG remains the supported download.

## Validation

- Goal reliability Definition of Done A–J completed with regression and integration tests. The isolated Docker Worker/D1 lane passed with a real local Worker-to-D1 read-back; synthetic owner evidence remains distinct from real authorization.
- Windows frontend tests passed 84/84 on the CI-pinned Node 22.12.0; production frontend build passed.
- Windows smoke and packaging contracts passed locally: desktop lifecycle 17/17, installer 22/22, release preparation 14/14, updater manifest/signature contract 10/10, Goal environment 13/13, and checkpoint staging 3/3.
- Release publication is gated on the clean-source, public-history/secret-scan, Apple Silicon packaging, Windows-hosted installation/upgrade, and signed updater-manifest jobs in GitHub Actions.

## Windows signing note

The updater archive is signed with the Tauri updater key and its matching public verification key. This is separate from Authenticode signing; the initial installer does not have Authenticode signing or SmartScreen reputation unless a separate certificate is configured.
