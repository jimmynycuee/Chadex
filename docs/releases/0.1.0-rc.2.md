# Chadex 0.1.0 RC2

This release candidate replaces RC1 as the first downloadable public build. RC1 reached GitHub Actions but did not publish a Release because the source gate exposed a localization portability issue on the English GitHub macOS runner.

## Changes since RC1

- Resolve explicit zh-Hant / en localization bundles independently of the host macOS preferred language.
- Keep the release source, Gitleaks history scan, Hardened Runtime ad-hoc signing, ARM64 DMG smoke test, and SHA-256 publication gates unchanged.
- Select GitHub Release notes from the exact release tag instead of a hard-coded RC1 file.

## Distribution

This Apple Silicon (arm64) build is ad-hoc signed with Hardened Runtime and is not notarized. On first launch, macOS may require System Settings → Privacy & Security → Open Anyway. Do not disable Gatekeeper globally.

Developer ID signing and Apple notarization remain an optional future upgrade.
