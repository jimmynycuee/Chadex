# Chadex 0.6.3

Chadex 0.6.3 fixes how the macOS release is built. Public distribution remains the macOS Apple Silicon DMG; the Windows application remains an unsigned CI validation candidate.

## Changes

- **macOS 26 SDK for release builds**: releases up to 0.6.2 were built on the `macos-15` runner and linked the macOS 15.5 SDK. On macOS 26 and later such an app runs in compatibility mode, so it showed old-style rounded-rectangle buttons instead of capsules, and the Liquid Glass code (guarded by `#if compiler(>=6.2)`) was not compiled in at all. CI and release builds now run on `macos-26`, and the release build fails if the app links an SDK older than 26.
- With the new SDK, the design v2 work from 0.6.0–0.6.2 now appears in the released app: capsule buttons with centred labels and the Liquid Glass sidebar.

## Known limitations

The 0.6.0 limitations still apply. See `docs/releases/0.6.0.md`.

## Validation

- A `workflow_dispatch` test build on `macos-26` linked SDK 26.5; the maintainer checked that CI-built app on a physical Mac and accepted the button shape.
- The tag's Free Release workflow runs the source release gate, the ARM64 DMG package gate and the new SDK check.

## Distribution boundary

`.github/workflows/release.yml` remains the free macOS distribution path and does not publish the Windows candidate. Publishing Windows assets, enabling a Windows updater or changing the signing policy requires a separate explicit release decision.
