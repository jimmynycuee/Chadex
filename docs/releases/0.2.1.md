# Chadex 0.2.1

Chadex 0.2.1 is a focused updater reliability release.

## Fixes

- **Safe updater shutdown.** The updater now completes the bounded Chadex shutdown before marking the application update-ready and terminating immediately, avoiding re-entry into the deferred normal-quit path.
- **No duplicate app instances.** The external installer no longer uses `open -n` for fallback, rollback, or post-install launch, preventing failed update attempts from creating extra Chadex processes.
- **Fail-closed termination setup.** If the update-specific shutdown handler is unavailable, the prepared update is discarded instead of starting an installer that cannot safely replace the running app.
- **Regression coverage.** The Swift suite explicitly verifies immediate post-shutdown termination and absence of forced duplicate-instance launches.

## Validation

- Swift full suite: 38/38 passed.
- Updater-specific tests: 7/7 passed.
- A fixed local 0.2.0 build is retained for an end-to-end in-app update test to 0.2.1 after publication.

## Upgrade note

The public 0.2.0 updater can fail to terminate Chadex and may reopen another 0.2.0 instance. Install 0.2.1 manually once if that happens. Versions containing this fix can perform the normal in-app update flow without forcing duplicate application instances.
