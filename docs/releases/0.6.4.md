# Chadex 0.6.4

Chadex 0.6.4 makes macOS buttons follow the interface size. Public distribution remains the macOS Apple Silicon DMG; the Windows application remains an unsigned CI validation candidate.

## Changes

- **Chadex glass buttons (macOS)**: with the macOS 26 SDK, native bordered buttons ignore `.font` and barely grow with the control size (measured 76×24 at regular to 88×36 at extraLarge, label unchanged), so buttons stayed small at 140–160%. A new `ChadexButtonStyle` draws the label at the interface scale inside a Liquid Glass capsule (blue tint for primary actions, red text for destructive ones). A sample button now measures 62×22 at 80% and 120×43 at 160%. All 37 bordered buttons use it.
- **No jump while connecting**: the busy spinner inside the connect/disconnect button is held to 12 pt, so the button no longer grows when you press Connect.

## Known limitations

The 0.6.0 limitations still apply. See `docs/releases/0.6.0.md`. Toggles and segmented controls are still native and do not grow with the interface size.

## Validation

- A `workflow_dispatch` build on `macos-26` (run 38052007198, SDK 26.5) was checked by the maintainer on a physical Mac at 80–160%, in light and dark mode, including connect/disconnect.
- The tag's Free Release workflow runs the source release gate, the ARM64 DMG package gate and the SDK check.

## Distribution boundary

`.github/workflows/release.yml` remains the free macOS distribution path and does not publish the Windows candidate. Publishing Windows assets, enabling a Windows updater or changing the signing policy requires a separate explicit release decision.
