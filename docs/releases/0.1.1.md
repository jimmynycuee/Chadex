# Chadex 0.1.1

Chadex 0.1.1 is a performance and reliability patch release focused on longer coding tasks.

## Highlights

- Reduce avoidable model/tool round trips during long coding tasks.
- Coalesce compatible same-path text edits so one logical mutation does not fail on harmless batching shape.
- Return a bounded diff preview after structured edits and guide the agent to review scope before expensive validation.
- Keep workflow guidance inside explicit item, per-item, and serialized-size budgets so startup context cannot grow silently.
- Shorten the advisory semantic-navigation startup probe from 2 seconds to 750 ms without disabling later explicit LSP tools.
- Preserve fail-closed edit guards when same-path changes use different revisions or incompatible mutation kinds.

## Benchmark follow-up

On the repeated Large3 coding benchmark, the Chadex session-level business-tool span decreased from about 401 seconds on the previous optimized run to about 241 seconds on the 0.1.1 candidate. Local tool execution time stayed roughly flat, indicating that the improvement came primarily from less orchestration rework rather than faster shell execution.

This timing is session-ledger evidence, not a full prompt-to-final-response wall-clock measurement.

## Distribution

This Apple Silicon (`arm64`) build uses Hardened Runtime with ad-hoc signing and is not notarized. On first launch, macOS may require **System Settings → Privacy & Security → Open Anyway**.

Developer ID signing and Apple notarization remain optional future upgrades.
