# Chadex 0.3.1

Chadex 0.3.1 adds Code Ferret, an animated native companion that reflects observed local tools, tasks, and durable Jobs. It builds on the official v0.3.0 release and preserves its long-job execution and observation contracts.

## Code Ferret

- Eleven dedicated poses cover idle, listening, thinking, repository search, coding, validation, waiting, long tasks, success, error, and sleep.
- Continuous silhouettes, localized eyelid overlays, anchored tails, breathing, cyan glow, and native work UI provide motion without cycling whole static character images.
- Actual task-step progress is shown only when a total is known. Generic commands are not assumed to be tests; silent remote reasoning is not observable.
- Durable Jobs stay visible after their HTTP response finishes. Observation is bounded to the selected exact project; failure, truncation, recovery, and unknown state never invent completion.
- Diagnostic calls do not repeatedly wake the companion. Ordinary tool responses are distinguished from successful terminal Jobs or completed tasks.
- Visibility and motion controls, macOS Reduce Motion, inactive-window rendering pauses, and English/Traditional Chinese labels are supported.

Architecture, assets, and the event mapping are documented in [`CODE_FERRET.md`](../CODE_FERRET.md).

## Validation limits

Local packaged-runtime validation is not a new connected ChatGPT Web E2E run. The mascot cannot observe private model thinking between tool requests. All eleven poses were rendered in automated light/dark review; the installed UI check covered the states listed above, not every possible live task flow. A truncated Job inventory remains unknown rather than silently excluding older work. Existing broad visual-review geometry and runtime dead-code warnings did not fail the gates.

## Compatibility and distribution

No data migration is required from v0.3.0. Existing project permissions, credential scope, the stable DMG updater contract, and durable-job retry policy are unchanged. Codex's separate native pet is unchanged.

The free release remains macOS 14+, Apple Silicon (`arm64`), Hardened Runtime, ad-hoc signed, and not notarized. Assets are `Chadex-v0.3.1-macos-arm64.dmg` and its `.sha256` sidecar. First launch may require **System Settings → Privacy & Security → Open Anyway**.
