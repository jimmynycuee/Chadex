# Chadex 0.3.1

**Status: unreleased candidate. Build, package, installed-app, and release validation are pending.**

Chadex 0.3.1 adds Code Ferret, an animated mascot that presents observed local tool and task activity. The candidate builds on the official v0.3.0 release.

## Code Ferret

- Displays idle, request-received, thinking, searching, coding, testing, waiting, long-task, success, error, and sleep presentations from the available runtime evidence.
- Shows measured task-step progress only when a total is known; unknown work has no invented completion percentage. The mascot is not evidence of internal model reasoning or token activity.
- Distinguishes task completion from an ordinary tool response, and resets its reactions when the selected project changes.
- Provides visibility and motion controls, macOS Reduce Motion support, and English / Traditional Chinese labels.
