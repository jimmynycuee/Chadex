# Chadex 0.7.3

## Highlights

- **Visible update progress on macOS:** after you click the sidebar **Update** button it keeps its color and shows a spinner with 「更新中…」 while the release downloads and verifies, then 「重新啟動中…」 while it installs. The tooltip gives the full status, and the label no longer truncates.
- **Simpler Plans list:** the Plan & Goal page lists only the most recently updated plan that is still in drafting. Approved plans continue as Goal runs.
- **Windows guide:** a new 使用說明 page follows the macOS guide's steps and links, using the Windows app's own button names and its system-tray behavior. Steps tick off from the app's real state. A fresh install shows a pointer to the guide on the home page. Its links open in the default browser through a fixed allowlist.
- **Windows automatic update checks:** the app checks for updates shortly after launch and again on focus after six hours, the same cadence as macOS. It only checks; installing still needs a click. When an update is found, a sidebar button appears that shows progress while installing and waits while work is running. Automatic checks can be turned off on the updates page.
- **macOS guide:** the 「遇到問題？」 troubleshooting section and the note on what the test prompt checks are now shown.

## Upgrading

- macOS: use the in-app **Update** button, or download the DMG.
- Windows v0.7.2: open 版本與更新 and choose 檢查更新 to install v0.7.3 from the app. Automatic checks and the sidebar button start with v0.7.3.
- Windows v0.7.1 and earlier: install v0.7.3 manually once; those versions have no in-app updater.

## Validation

- Pull request CI on the merged change (jimmynycuee/Chadex#34) passed every job: macOS source and ARM64 package gates; Windows core gate, W5 source integrity, installer candidate (install, upgrade, relaunch, reinstall, uninstall) and historical v0.7.1 upgrade.
- Windows frontend tests pass 93/93, including coverage for the guide, update auto-check timing, quiet automatic-check failures, the opt-out, the sidebar button and the running-work guard, plus a check that the UI never touches WebView storage. The update and guide settings live in the app's preferences file, so the app data folder holds only files Chadex writes itself.
- For this release the Windows synthetic and historical upgrade baselines advance from v0.7.1 to v0.7.2.

## Known boundaries

- The macOS DMG is ad-hoc signed and not notarized. The Windows installer is not Authenticode-signed; its updater archive is signed with the Tauri updater key.
- The new UI states were exercised by automated tests and a browser preview of the Windows guide. Physical-device checks of the update buttons remain manual.
