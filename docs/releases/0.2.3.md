# Chadex 0.2.3

Chadex 0.2.3 fixes duplicate main windows when reopening the app from the Dock after closing its last visible window.

## Fixes

- **Single-window Dock reopen.** When Chadex manually restores the main SwiftUI window, the app delegate now returns `false` so AppKit does not also perform its default reopen path and create a second main window.
- **Regression coverage.** App lifecycle tests now verify that a hidden-window Dock reopen invokes the manual main-window handler exactly once and suppresses the default AppKit reopen, while the visible-window path keeps the normal behavior.

## Validation

- Focused `AppLifecycleTests`: passed.
- Full source release gate: passed, including the Swift suite, Rust helper tests, runtime all-target compilation, release-critical Rust tests, production runtime wrapper check, release tooling tests, and repository diff hygiene.
- Release-profile ARM64 app build: passed.
- Ad-hoc signed free-release DMG packaging: passed.

## Upgrade note

Users on 0.2.2 can update directly to 0.2.3. This release only changes the Dock reopen lifecycle and release-version metadata; no migration is required.
