# Chadex 0.2.2

Chadex 0.2.2 fixes the packaged-app resource crash discovered in 0.2.1 and makes available updates much more visible.

## Fixes

- **Packaged-app launch crash fixed.** Localization no longer depends on SwiftPM's generated `Bundle.module` accessor at runtime. Chadex resolves its resource bundle from the normal macOS `Contents/Resources` layout and degrades safely instead of terminating the app if localization resources cannot be resolved.
- **Updater resource validation.** A downloaded candidate is rejected before installation unless the Chadex resource bundle and required English and Traditional Chinese localization files are present.
- **Release-path resource preflight.** Free-release packaging now executes the packaged Chadex binary before DMG creation and again from the mounted DMG, catching resource lookup failures that file-existence checks alone cannot detect.
- **Prominent in-app Update button.** When a newer stable release is available, Chadex shows a blue **Update** button beside Settings in the main sidebar and routes it through the existing guarded update flow.

## Validation

- Swift full suite: 39/39 passed.
- Release-profile app build: passed.
- Packaged app resource preflight: passed.
- Ad-hoc signed free-release build and mounted-DMG resource preflight: passed.

## Upgrade note

The public 0.2.1 DMG can install successfully and then crash at launch because its release binary may fail to locate the SwiftPM localization bundle. Upgrade to 0.2.2. Users still on 0.2.0 can skip 0.2.1 and install the latest stable release directly.
