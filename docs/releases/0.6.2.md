# Chadex 0.6.2

Chadex 0.6.2 is a patch release for macOS button shape. Public distribution remains the macOS Apple Silicon DMG; the Windows application remains an unsigned CI validation candidate.

## Changes

- **Capsule buttons (macOS)**: 0.6.1 set the capsule button shape at the window root, but the value did not reach buttons inside the window's container views, so they stayed rounded rectangles. The shape is now set on each scaled control, so buttons match the status pills.

## Known limitations

The 0.6.0 limitations still apply. See `docs/releases/0.6.0.md`.

## Validation

- The maintainer accepted the dev build on a physical Mac.
- The tag's Free Release workflow runs the source release gate and the ARM64 DMG package gate. The full pull-request CI matrix was not waited on for this release, at the maintainer's request.

## Distribution boundary

`.github/workflows/release.yml` remains the free macOS distribution path and does not publish the Windows candidate. Publishing Windows assets, enabling a Windows updater or changing the signing policy requires a separate explicit release decision.
