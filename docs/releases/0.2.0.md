# Chadex 0.2.0

Chadex 0.2.0 introduces in-app updates and hardens long-running ChatGPT workflows against host-side waiting failures.

## Highlights

- **In-app updates.** Chadex can check the latest stable GitHub Release, download the exact Apple Silicon DMG + SHA-256 pair, verify the checksum, bundle identifier, version, architecture, and macOS code signature, then stage the candidate beside the current app.
- **Safe update swap and rollback.** Installation happens in an external helper after Chadex shuts down normally. The previous app stays available as a temporary backup until the new version launches and reports a version-bound health marker; failed launches automatically roll back.
- **Host-safe long-job observation.** Model-facing `observe_jobs` uses a 20-second canonical wait and clamps longer requests to 30 seconds, while the underlying Runner job can continue for minutes or longer.
- **Explicit long-job handoff metadata.** Job responses now include `recommended_poll_after_secs` and parser-ready 20-second continuations, reducing long blocking tool turns.
- **Polling discipline.** Built-in coding guidance now avoids `sleep` / shell polling for visibility and prefers native external status connectors when available.
- Includes the 0.1.1 long-task orchestration improvements, bounded diff review, same-path edit coalescing, workflow budget guards, and faster advisory semantic-navigation startup probing.

## Upgrade note

0.2.0 is the first public version that contains the in-app updater, so users on 0.1.1 still need to install 0.2.0 manually once. After 0.2.0 is installed, future stable GitHub releases can be checked and installed from inside Chadex.

## Distribution

The free GitHub release is Apple Silicon (`arm64`), Hardened Runtime enabled, ad-hoc signed, and not notarized. macOS may require **System Settings → Privacy & Security → Open Anyway** on first launch.
