# Chadex 0.6.0 (draft)

Chadex 0.6.0 is a design and Computer Use polish release. It is expected to bring the second-generation visual design to macOS and Windows, add a permission card to the Computer Use page, and tighten Computer Use timing and test reliability. Public distribution remains the macOS Apple Silicon DMG; the Windows application remains an unsigned CI validation candidate.

This is a draft. The listed changes are the open PRs expected to be included (jimmynycuee/Chadex); none have been merged yet, so the list and the validation section must be updated at release time.

## Expected changes

### Design v2

- **Windows (#1)**: Fluent type scale, connection circuit, activity timeline, Mica backdrop, dark as the default appearance.
- **macOS (#2)**: Liquid Glass sidebar, connection circuit, activity timeline, dark as the default appearance, and a fix so the app builds on the macOS 15 SDK used by CI.

### Computer Use

- **Permission card (#4)**: the Computer Use page shows Accessibility and Screen Recording status in a card, with granted permissions in green.
- **Window activation (#5)**: the tool descriptions only call `activate_window` before key or pointer actions.
- **Timing log (#6)**: every Computer Use action records its elapsed time.

### Test and CI reliability

- **W5 smoke (#3)**: the smoke run prints unexpected exceptions, and the `process_inventory` time limit goes from 15 to 60 s.
- **Runtime tests (#7)**: the environment-variable races in runtime tests are fixed at the root.

### Candidates, not included yet

These were originally planned for 0.6.1 and are included only if they merge before the release:

- **Cursor overlay on macOS (#8)**: needs a real-machine check that the overlay is excluded from screenshots.
- **Chromium web-page AX (#9)**.

## Known limitations

- **macOS design v2 is pending validation.** It has been reviewed by AI reviewers only. There is no external design validation and no user acceptance on a physical machine yet, so it must not be described as award-level or externally validated.
- **Windows is verified in CI only.** There has been no physical-machine testing of the Windows design v2 or any other Windows change.
- The 0.5.0 limitations still apply: a ChatGPT session with the bootstrap token still has full permissions, hidden `$` shares cannot be Skill sources, and removing a Skill affects every project on the local runtime.

## Validation

To be filled in at release time. Required before release: `release_check.sh` exit 0, full CI success on the release commit, user acceptance of `dist/Chadex.app`, and, if #8 is included, a real-machine test that the cursor overlay is excluded from screenshots. The Windows CI historical-upgrade gate now builds the public `v0.5.0` tag and upgrades it to the 0.6.0 candidate, and the synthetic installer-migration fixture models `0.5.0 → 0.6.0`.

## Distribution boundary

`.github/workflows/release.yml` remains the free macOS distribution path and does not publish the Windows candidate. Publishing Windows assets, enabling a Windows updater or changing the signing policy requires a separate explicit release decision.
