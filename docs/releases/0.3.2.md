# Chadex 0.3.2

Chadex 0.3.2 improves Code Ferret's runtime state judgment and activity dwell. Fast work remains visible, idle connection verification no longer looks like blocked work, and real waits remain distinct from long tasks. It preserves the character, animation assets, and v0.3.1 runtime execution contracts.

## Changes

- Fresh observed work gets a one-second listening reaction. Restored history, queued work, recovery, and cancellation do not replay a received-prompt reaction.
- Successful ordinary work-tool responses retain their actual activity for two seconds, labelled **Recently…** / **剛才…**. Repeated snapshots do not renew this hold; it is coalesced rather than queued.
- Connection readiness awaiting project verification can idle or sleep when no work is observed. Actual blocked, unknown, recovering, queued, and cancellation states remain Waiting, including after 60 seconds.
- Symbol navigation and project overview map to Search Repo; `write_project_file` and `apply_unified_diff` to Coding; `go_test` to Running Tests. Generic shell commands are not assumed to be tests.
- Live scoped tools provide more specific activity than generic durable process Jobs. Long Task timing uses that selected activity's start rather than an unrelated older wait. Fast recent activity can remain visible during generic running Jobs, without covering known task steps or real waits.
- New observed work supersedes older success/error reactions. Simultaneous successful task/Job outcomes cannot erase a failure. When no new work arrives, Success retains three seconds and Error five seconds.
- Diagnostic polling, including `observe_task` and `list_jobs`, does not wake the companion or consume reactions.
- Local fixtures and preserved worktrees are explicitly excluded from Git/Graphify source indexing. Benchmark defaults follow the canonical local-fixtures directory. Uncommitted runtime and Windows work is preserved separately and is not part of this release.

Foreground/background polling, the animation clock, visibility/motion preferences, and credential scope are unchanged. No dependencies or character assets were added. Architecture and event mapping remain in [`CODE_FERRET.md`](../CODE_FERRET.md).

## Limits and compatibility

Silent host/model thinking is not observable. Generic durable Jobs lack a command-purpose field in the mascot snapshot; without a scoped tool or task step they use Thinking/Long Task rather than guessing validation. Live UI inspection and deterministic transition tests are distinct evidence; no new connected ChatGPT Web E2E run or performance benchmark is claimed.

No data migration is required. Existing project permissions, credential scope, updater contract, and durable-job retry policy remain intact. Codex's separate native pet is unchanged.

The free release supports macOS 14+ and Apple Silicon (`arm64`), uses Hardened Runtime with ad-hoc signing, and is not notarized. Artifacts are `Chadex-v0.3.2-macos-arm64.dmg` and its `.sha256` sidecar. First launch may require **System Settings → Privacy & Security → Open Anyway**. Intel/Universal support is not claimed.
